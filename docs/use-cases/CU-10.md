# CU-10: Eliminar un proyecto

| Campo | Descripción |
|---|---|
| Actor | Líder de proyecto o administrador. |
| Objetivo | Eliminar un proyecto, todas sus tareas y sus permisos de acceso. |
| Precondiciones | Actor autenticado mediante CU-02; existe el proyecto identificado por su sigla. |
| Resultado esperado | Proyecto, todas sus tareas y todos sus permisos de acceso eliminados en una transacción; operaciones registradas en logs. |
| Requerimientos | RF-09, RF-10, RF-16, RF-17, RF-18, RF-19, RF-21, RNF-02, RNF-03. |

**Flujo principal**

- **CU-10.1:** El actor identifica el proyecto por su sigla y solicita eliminarlo.
- **CU-10.2:** El sistema verifica que el actor sea líder con acceso al proyecto o administrador.
- **CU-10.3:** El sistema elimina el proyecto, todas sus tareas y todos sus permisos de acceso en una misma transacción de base de datos.
- **CU-10.4:** El sistema registra las eliminaciones conforme a RF-09, incluyendo el identificador del proyecto en los registros de sus tareas, e informa el resultado. Finaliza el caso.

**Flujos de excepción**

**CU-10.E1: Operación no autorizada**

Desencadenante: paso CU-10.2, cuando el actor carece del rol o del acceso requerido.

- **CU-10.E1.1:** El sistema rechaza la operación sin eliminar el proyecto, sus tareas ni sus permisos.

Continuación: finaliza el caso.

**Consideraciones**

- La eliminación de las tareas es parte de esta operación; no exige ejecutar CU-16 individualmente para cada una.
- Los permisos de acceso se eliminan junto con el proyecto. Si falla la transacción, se revierten también las eliminaciones de tareas y permisos.
- Los requerimientos no definen confirmaciones adicionales ni recuperación de proyectos.
