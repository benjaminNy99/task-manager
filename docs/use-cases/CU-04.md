# CU-04: Consultar usuarios

| Campo | Descripción |
|---|---|
| Actor | Administrador. |
| Objetivo | Consultar las cuentas de usuario existentes. |
| Precondiciones | Actor autenticado mediante CU-02. |
| Resultado esperado | Información de usuarios consultada por un administrador, sin cambios en los datos. |
| Requerimientos | RF-10, RF-24, RNF-02, RNF-03, RNF-09. |

**Flujo principal**

- **CU-04.1:** El administrador solicita consultar usuarios.
- **CU-04.2:** El sistema verifica que el actor sea administrador.
- **CU-04.3:** El sistema consulta las cuentas existentes y presenta su información identificativa y de roles, excluyendo contraseñas y hashes del resultado. Finaliza el caso.

**Flujos de excepción**

**CU-04.E1: Actor sin permiso para consultar usuarios**

Desencadenante: paso CU-04.2, cuando el actor no es administrador.

- **CU-04.E1.1:** El sistema rechaza la consulta sin mostrar los usuarios.

Continuación: finaliza el caso.

**Consideraciones**

- RF-24 habilita la consulta de usuarios; no define filtros, orden ni paginación.
