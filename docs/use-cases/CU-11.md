# CU-11: Gestionar el acceso a un proyecto

| Campo | Descripción |
|---|---|
| Actor | Líder de proyecto o administrador. |
| Objetivo | Conceder o revocar el permiso de acceso de un usuario a un proyecto. |
| Precondiciones | Actor autenticado mediante CU-02; existen el proyecto y el usuario destinatario. Para revocar un permiso, este existe. |
| Resultado esperado | Permiso concedido o revocado y cambio registrado en logs. |
| Requerimientos | RF-09, RF-10, RF-16, RF-17, RF-18, RF-25, RNF-02, RNF-03. |

**Flujo principal**

- **CU-11.1:** El actor identifica el proyecto por su sigla, indica el usuario destinatario y solicita concederle acceso.
- **CU-11.2:** El sistema verifica que el actor sea líder con acceso al proyecto o administrador.
- **CU-11.3:** El sistema persiste el permiso de acceso del usuario al proyecto.
- **CU-11.4:** El sistema registra el cambio conforme a RF-09 e informa el resultado. Finaliza el caso.

**Flujos alternativos**

**CU-11.A1: Revocar un permiso de acceso**

Desencadenante: paso CU-11.1, cuando el actor solicita revocar un permiso existente en lugar de concederlo.

- **CU-11.A1.1:** El actor indica el proyecto y el usuario cuyo permiso desea revocar.

Continuación: continúa en CU-11.2; en CU-11.3 se elimina el permiso indicado en lugar de concederlo y se prosigue en CU-11.4.

**Flujos de excepción**

**CU-11.E1: Operación no autorizada**

Desencadenante: paso CU-11.2, cuando el actor carece del rol o del acceso requerido.

- **CU-11.E1.1:** El sistema rechaza la operación sin cambiar los permisos.

Continuación: finaliza el caso.

**Consideraciones**

- Conceder acceso no cambia los roles del destinatario. Las operaciones disponibles dependen además de sus capacidades.
- Revocar un permiso explícito a un administrador no elimina su acceso global por rol.
- Falta definir el tratamiento de las tareas cuyo encargado pierda acceso y las reglas, si las hubiera, para revocar el propio acceso o el del creador del proyecto.
- No se especifica el resultado de conceder un permiso ya existente ni de solicitar la revocación de uno inexistente.
