# CU-01: Crear el administrador inicial

| Campo | Descripción |
|---|---|
| Actor | Persona que configura el administrador inicial. |
| Objetivo | Crear la primera cuenta administradora disponible para gestionar el sistema. |
| Precondiciones | No existe ningún administrador. No se requiere autenticación previa. |
| Resultado esperado | Cuenta creada con identificador positivo incremental, nombre y contraseña protegida; indicador de administrador activado, sin generar auditoría. |
| Requerimientos | RF-10, RF-14, RF-23, RF-24, RF-26, RNF-01, RNF-02, RNF-03; excepción de auditoría de RF-09. |

**Flujo principal**

- **CU-01.1:** El actor ejecuta el comando de creación del administrador inicial.
- **CU-01.2:** El sistema comprueba que no existe un administrador y solicita el nombre y la contraseña de la nueva cuenta.
- **CU-01.3:** El actor proporciona el nombre y la contraseña.
- **CU-01.4:** El sistema valida que el nombre contenga únicamente letras de A a Z, en mayúsculas o minúsculas, y dígitos del 0 al 9, y que sea único sin distinguir mayúsculas y minúsculas.
- **CU-01.5:** El sistema asigna el identificador numérico positivo incremental, establece la cuenta como administradora y guarda su contraseña mediante un hash seguro para contraseñas, sin conservarla en texto plano.
- **CU-01.6:** El sistema persiste la cuenta sin generar auditoría e informa que el administrador fue creado. Finaliza el caso.

**Flujos de excepción**

**CU-01.E1: Ya existe un administrador**

Desencadenante: paso CU-01.2, cuando existe al menos una cuenta administradora.

- **CU-01.E1.1:** El sistema no habilita la creación del administrador inicial.

Continuación: finaliza el caso sin crear la cuenta.

**CU-01.E2: Nombre no válido o duplicado**

Desencadenante: paso CU-01.4, cuando el nombre incumple las reglas de formato o unicidad.

- **CU-01.E2.1:** El sistema informa del incumplimiento y no crea la cuenta.

Continuación: finaliza el caso sin crear la cuenta.

**Consideraciones**

- Este comando no exige `--user` ni `--pass` para autenticar a un usuario previo. La contraseña solicitada corresponde a la cuenta que se crea.
- La inicialización se ofrece exclusivamente mediante este comando; no existe un flujo de creación inicial en la TUI.
- Este caso no genera auditoría, tanto si crea la cuenta como si falla.
