# CU-05: Modificar un usuario

| Campo | Descripción |
|---|---|
| Actor | Administrador. |
| Objetivo | Actualizar el nombre, la contraseña o los indicadores de rol de una cuenta. |
| Precondiciones | Actor autenticado mediante CU-02; existe la cuenta que se desea modificar. |
| Resultado esperado | Cuenta actualizada y modificación registrada en logs. |
| Requerimientos | RF-09, RF-10, RF-14, RF-16, RF-24, RNF-01, RNF-02, RNF-03. |

**Flujo principal**

- **CU-05.1:** El administrador identifica la cuenta y proporciona los cambios solicitados.
- **CU-05.2:** El sistema verifica que el actor sea administrador.
- **CU-05.3:** Si cambia el nombre, el sistema valida que no contenga espacios ni caracteres especiales y que no coincida con el de otra cuenta, sin distinguir mayúsculas y minúsculas.
- **CU-05.4:** El sistema aplica los cambios solicitados. Si cambia la contraseña, prepara su hash seguro sin conservarla en texto plano; si cambian los roles, conserva la representación mediante los tres indicadores booleanos.
- **CU-05.5:** El sistema persiste la actualización, registra la modificación conforme a RF-09 e informa el resultado. Finaliza el caso.

**Flujos de excepción**

**CU-05.E1: Actor sin permiso para modificar usuarios**

Desencadenante: paso CU-05.2, cuando el actor no es administrador.

- **CU-05.E1.1:** El sistema rechaza la operación sin modificar la cuenta.

Continuación: finaliza el caso.

**CU-05.E2: Nombre no válido o duplicado**

Desencadenante: paso CU-05.3, cuando el nuevo nombre incumple las reglas de formato o unicidad.

- **CU-05.E2.1:** El sistema informa del incumplimiento sin guardar la modificación solicitada.

Continuación: finaliza el caso.

**Consideraciones**

- RF-14 mantiene pendiente el conjunto exacto de caracteres admitidos en nombres de usuario.
- Los permisos siguen la jerarquía de RF-16 aunque los roles inferiores no estén activados.
- No se define una restricción para cambiar los propios roles ni una política para retirar el rol al último administrador. Este caso no introduce tales restricciones.
