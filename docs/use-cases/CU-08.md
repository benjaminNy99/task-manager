# CU-08: Consultar y seleccionar proyectos

| Campo | Descripción |
|---|---|
| Actor | Contribuyente, líder de proyecto o administrador. |
| Objetivo | Identificar los proyectos disponibles y seleccionar uno mediante su sigla. |
| Precondiciones | Actor autenticado mediante CU-02. |
| Resultado esperado | Proyectos permitidos consultados y, si se solicita, un proyecto autorizado seleccionado. |
| Requerimientos | RF-10, RF-12, RF-13, RF-16, RF-17, RF-18, RF-19, RNF-02, RNF-03. |

**Flujo principal**

- **CU-08.1:** El actor solicita visualizar los proyectos disponibles.
- **CU-08.2:** El sistema verifica las capacidades del actor y determina los proyectos a los que tiene acceso: todos para un administrador, únicamente los autorizados para los demás roles indicados.
- **CU-08.3:** El sistema presenta los proyectos disponibles, representados mediante sus siglas, pudiendo mostrar varios a la vez.
- **CU-08.4:** El actor indica la sigla del proyecto que desea seleccionar.
- **CU-08.5:** El sistema identifica el proyecto sin distinguir mayúsculas y minúsculas y verifica que el actor tenga acceso.
- **CU-08.6:** El sistema establece el proyecto seleccionado para la operación solicitada. Finaliza el caso.

**Flujos alternativos**

**CU-08.A1: Consulta sin selección**

Desencadenante: paso CU-08.4, cuando el actor únicamente solicita consultar los proyectos disponibles.

- **CU-08.A1.1:** El sistema conserva como resultado la consulta realizada en CU-08.3.

Continuación: finaliza el caso sin seleccionar un proyecto.

**CU-08.A2: Selección directa por sigla**

Desencadenante: paso CU-08.1, cuando el actor ya proporciona la sigla para seleccionar un proyecto sin solicitar el listado.

- **CU-08.A2.1:** El sistema recibe la sigla indicada y realiza la comprobación de capacidades de CU-08.2.

Continuación: continúa en CU-08.5.

**Flujos de excepción**

**CU-08.E1: Proyecto no disponible para el actor**

Desencadenante: paso CU-08.5, cuando la sigla no identifica un proyecto existente o el actor no tiene acceso.

- **CU-08.E1.1:** El sistema no selecciona el proyecto ni permite consultar sus tareas.

Continuación: finaliza el caso sin la selección solicitada.

**CU-08.E2: Actor sin capacidades de consulta**

Desencadenante: paso CU-08.2, cuando el actor no dispone de ninguno de los roles indicados.

- **CU-08.E2.1:** El sistema rechaza la consulta o selección.

Continuación: finaliza el caso.

**Consideraciones**

- La selección puede ser parte de un comando o de una interacción; no presupone una selección persistente entre ejecuciones.
- Para consultar las tareas del proyecto seleccionado se utiliza [CU-13](CU-13.md).
