# CU-03: Crear un usuario

| Campo | Descripción |
|---|---|
| Actor | Administrador. |
| Objetivo | Registrar una cuenta de usuario y sus indicadores de rol. |
| Precondiciones | Actor autenticado mediante CU-02. |
| Resultado esperado | Usuario persistido con identificador positivo incremental, nombre único, contraseña protegida e indicadores de rol; creación registrada en logs. |
| Requerimientos | RF-09, RF-10, RF-14, RF-16, RF-24, RNF-01, RNF-02, RNF-03. |

**Flujo principal**

- **CU-03.1:** El administrador solicita crear un usuario con nombre, contraseña y los valores booleanos de administrador, líder de proyecto y contribuyente.
- **CU-03.2:** El sistema verifica que el actor sea administrador.
- **CU-03.3:** El sistema valida que el nombre contenga únicamente letras de A a Z, en mayúsculas o minúsculas, y dígitos del 0 al 9, y que sea único sin distinguir mayúsculas y minúsculas.
- **CU-03.4:** El sistema asigna el identificador numérico positivo incremental y prepara la cuenta con sus indicadores de rol. Protege la contraseña mediante un hash seguro para contraseñas, sin conservarla en texto plano.
- **CU-03.5:** El sistema persiste la cuenta, registra la creación conforme a RF-09 e informa el resultado. Finaliza el caso.

**Flujos de excepción**

**CU-03.E1: Actor sin permiso para crear usuarios**

Desencadenante: paso CU-03.2, cuando el actor no es administrador.

- **CU-03.E1.1:** El sistema rechaza la operación sin crear la cuenta.

Continuación: finaliza el caso.

**CU-03.E2: Nombre no válido o duplicado**

Desencadenante: paso CU-03.3, cuando el nombre incumple las reglas de formato o unicidad.

- **CU-03.E2.1:** El sistema informa del incumplimiento sin crear la cuenta.

Continuación: finaliza el caso.

**Consideraciones**

- Los permisos son acumulativos por jerarquía aunque los indicadores de los roles inferiores estén desactivados.
- No se establecen valores predeterminados para los indicadores de rol.
