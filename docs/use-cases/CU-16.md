# CU-16: Eliminar una tarea

| Campo | Descripción |
|---|---|
| Actor | Contribuyente, líder de proyecto o administrador. |
| Objetivo | Eliminar una tarea de un proyecto. |
| Precondiciones | Actor autenticado mediante CU-02; existen el proyecto y la tarea identificada dentro de él. |
| Resultado esperado | Tarea eliminada y operación registrada en logs. |
| Requerimientos | RF-04, RF-09, RF-10, RF-16, RF-17, RF-18, RF-20, RNF-02, RNF-03. |

**Flujo principal**

- **CU-16.1:** El actor identifica el proyecto por su sigla y la tarea por su identificador dentro del proyecto, y solicita eliminarla.
- **CU-16.2:** El sistema verifica que el actor tenga capacidades de contribuyente y acceso al proyecto; el administrador dispone de acceso global.
- **CU-16.3:** El sistema elimina la tarea de la base de datos.
- **CU-16.4:** El sistema registra la eliminación conforme a RF-09 con los identificadores de tarea y proyecto e informa el resultado. Finaliza el caso.

**Flujos de excepción**

**CU-16.E1: Operación no autorizada**

Desencadenante: paso CU-16.2, cuando el actor carece del rol o del acceso requerido.

- **CU-16.E1.1:** El sistema rechaza la operación sin eliminar la tarea.

Continuación: finaliza el caso.

**Consideraciones**

- RF-20 permite eliminar tareas del proyecto autorizado sin limitar la operación al creador o al encargado.
- Los requerimientos no definen confirmaciones adicionales ni recuperación de tareas eliminadas.
