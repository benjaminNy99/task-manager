# CU-13: Consultar las tareas de un proyecto

| Campo | Descripción |
|---|---|
| Actor | Contribuyente, líder de proyecto o administrador. |
| Objetivo | Consultar las tareas de un proyecto, su estado y su urgencia. |
| Precondiciones | Actor autenticado mediante CU-02; existe el proyecto seleccionado por su sigla. |
| Resultado esperado | Tareas de un solo proyecto autorizado mostradas por estado, ordenadas y con los colores definidos. |
| Requerimientos | RF-04, RF-05, RF-07, RF-08, RF-10, RF-13, RF-16, RF-17, RF-18, RF-20, RNF-02, RNF-03. |

**Flujo principal**

- **CU-13.1:** El actor solicita consultar las tareas de un proyecto identificado mediante su sigla, seleccionándolo según CU-08 si necesita consultar los proyectos disponibles.
- **CU-13.2:** El sistema verifica que el actor tenga capacidades de contribuyente y acceso al proyecto; el administrador dispone de acceso global.
- **CU-13.3:** El sistema consulta exclusivamente las tareas del proyecto seleccionado y las agrupa en «No empezado», «En curso» y «Completado».
- **CU-13.4:** El sistema ordena las tareas de cada sección por prioridad descendente y, para prioridades iguales, por nombre en orden alfabético ascendente.
- **CU-13.5:** El sistema muestra las tres secciones y aplica el color de estado al nombre de la tarea y al nombre del estado: gris, amarillo y verde, respectivamente. El número de prioridad se muestra gris del 1 al 3, amarillo del 4 al 7 y rojo del 8 al 10. Finaliza el caso.

**Flujos de excepción**

**CU-13.E1: Operación no autorizada**

Desencadenante: paso CU-13.2, cuando el actor carece del rol o del acceso requerido.

- **CU-13.E1.1:** El sistema rechaza la consulta sin mostrar las tareas del proyecto.

Continuación: finaliza el caso.

**Consideraciones**

- Pueden visualizarse varios proyectos, pero las tareas presentadas a la vez pertenecen únicamente al seleccionado.
- No se definen filtros, búsqueda, actualización periódica ni orden adicional para tareas con la misma prioridad y el mismo nombre.
