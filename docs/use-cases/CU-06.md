# CU-06: Eliminar un usuario

| Campo | Descripción |
|---|---|
| Actor | Administrador. |
| Objetivo | Eliminar una cuenta de usuario. |
| Precondiciones | Actor autenticado mediante CU-02; existe la cuenta que se desea eliminar. |
| Resultado esperado | Cuenta eliminada y operación registrada en logs. |
| Requerimientos | RF-09, RF-10, RF-24, RNF-02, RNF-03, RNF-04. |

**Flujo principal**

- **CU-06.1:** El administrador identifica la cuenta y solicita eliminarla.
- **CU-06.2:** El sistema verifica que el actor sea administrador.
- **CU-06.3:** El sistema intenta eliminar la cuenta en la base de datos. Si el borrado se confirma, registra la eliminación conforme a RF-09.
- **CU-06.4:** El sistema informa el resultado. Finaliza el caso.

**Flujos de excepción**

**CU-06.E1: Actor sin permiso para eliminar usuarios**

Desencadenante: paso CU-06.2, cuando el actor no es administrador.

- **CU-06.E1.1:** El sistema rechaza la operación sin eliminar la cuenta.

Continuación: finaliza el caso.

**CU-06.E2: Borrado rechazado por asociaciones de datos**

Desencadenante: paso CU-06.3, cuando la base de datos rechaza el borrado por asociaciones de datos, como una restricción de clave foránea.

- **CU-06.E2.1:** El sistema conserva la cuenta y revierte los cambios de la transacción fallida conforme a RNF-04.
- **CU-06.E2.2:** El sistema registra el error conforme a RF-09 e informa al administrador: «No se puede eliminar el usuario por estar asociado a otros datos».

Continuación: finaliza el caso sin eliminar la cuenta.

**Consideraciones**

- No se han definido restricciones para eliminar la propia cuenta o la del último administrador. La disponibilidad del comando de inicialización depende de que no exista un administrador, según RF-26.
