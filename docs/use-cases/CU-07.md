# CU-07: Crear un proyecto

| Campo | Descripción |
|---|---|
| Actor | Líder de proyecto o administrador. |
| Objetivo | Registrar un proyecto con nombre y sigla para organizar tareas. |
| Precondiciones | Actor autenticado mediante CU-02. |
| Resultado esperado | Proyecto persistido con identificador positivo incremental y sigla única; creador con acceso concedido automáticamente y creación registrada en logs. |
| Requerimientos | RF-09, RF-10, RF-11, RF-12, RF-16, RF-18, RF-19, RNF-02, RNF-03. |

**Flujo principal**

- **CU-07.1:** El actor solicita crear un proyecto e indica su nombre y sigla.
- **CU-07.2:** El sistema verifica que el actor tenga capacidades de líder de proyecto o administrador.
- **CU-07.3:** El sistema valida que el nombre y la sigla no estén vacíos y contengan únicamente letras de A a Z, en mayúsculas o minúsculas, y dígitos del 0 al 9. Comprueba que la sigla sea única sin distinguir mayúsculas y minúsculas.
- **CU-07.4:** El sistema asigna un identificador numérico positivo incremental al proyecto y concede acceso automáticamente a su creador.
- **CU-07.5:** El sistema persiste el proyecto y el acceso, registra las operaciones conforme a RF-09 e informa el resultado identificando el proyecto por su sigla. Finaliza el caso.

**Flujos de excepción**

**CU-07.E1: Actor sin permiso para crear proyectos**

Desencadenante: paso CU-07.2, cuando el actor no dispone de capacidades de líder ni administrador.

- **CU-07.E1.1:** El sistema rechaza la operación sin crear el proyecto.

Continuación: finaliza el caso.

**CU-07.E2: Nombre o sigla no válidos, o sigla duplicada**

Desencadenante: paso CU-07.3, cuando el nombre o la sigla incumplen las reglas de formato, o la sigla incumple la unicidad.

- **CU-07.E2.1:** El sistema informa del incumplimiento sin crear el proyecto.

Continuación: finaliza el caso.

**Consideraciones**

- El nombre y la sigla no admiten espacios, caracteres especiales, acentos, ñ ni otros alfabetos.
- La concesión automática de acceso al creador también se aplica si este es administrador, aunque su rol ya le permita acceder a todos los proyectos.
